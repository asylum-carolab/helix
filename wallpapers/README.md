# Wallpapers

Fonds d'écran HELIX pour l'écran de verrouillage et les écrans d'accueil du Samsung Galaxy S24.

Sous-dossiers prévus : `lockscreen/` et `home/`.

## Versions validées PACK01

Les originaux sont conservés dans le package autonome, sans seconde copie inutile ici :

- [Accueil](../packages/HELIX-S24-PACK01/wallpapers/wallpaper%20helix.png)
- [Verrouillage](../packages/HELIX-S24-PACK01/wallpapers/verrouillage%20helix.png)

Voir [le guide S24](../packages/HELIX-S24-PACK01/README.md) pour leur sélection et le cadrage manuel. Les futurs sous-dossiers ci-dessus ne sont pas nécessaires à cette livraison.
