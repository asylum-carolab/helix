# HELIX

**HELIX // MOBILE NODE**

Interface I-Tech personnalisée pour Samsung Galaxy S24.

HELIX regroupe les ressources nécessaires à la personnalisation et au déploiement de l'interface : fonds d'écran, icônes, dossiers, widgets, sources graphiques et documentation.

## Direction visuelle

- noir / graphite / bleu nuit ;
- accents cyan et bleu lumineux ;
- touches ambrées discrètes ;
- esthétique moderne, technique et professionnelle ;
- identité visuelle cohérente sur l'ensemble du smartphone.

## Arborescence

- `wallpapers/` — fonds d'écran verrouillage et accueil ;
- `icons/` — icônes HELIX ;
- `folders/` — glyphes et ressources pour dossiers ;
- `widgets/` — ressources des widgets ;
- `sources/` — fichiers sources de création ;
- `packages/` — packs prêts au déploiement ;
- `docs/` — documentation et procédure d'installation.

## Cible

Samsung Galaxy S24.

---

HELIX est un projet personnel de personnalisation d'interface mobile.
