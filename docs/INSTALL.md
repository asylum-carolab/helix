# Installation de HELIX

Guide de déploiement pour Samsung Galaxy S24.

## Outils prévus

- Samsung Good Lock
- Theme Park
- Home Up

La procédure détaillée sera complétée au fur et à mesure de la validation des ressources HELIX.

## Installation PACK01

La procédure complète est maintenant disponible dans [le guide du package S24](../packages/HELIX-S24-PACK01/README.md) : icônes, fonds et sons. La recette physique reste à réaliser. Home Up est facultatif pour cette livraison.

## Personnalisation PACK02 — One UI 8.5

Après réinitialisation du S24, suivre [HELIX-PACK02](../packages/HELIX-S24-PACK02/README.md) pour installer Good Lock, ClockFace et LockStar, puis composer le bloc HELIX avec heure et date dynamiques. Ce complément conserve tous les fichiers PACK01 et le wallpaper original. Il précise les réglages visuels, les limites et la recette physique à effectuer.
